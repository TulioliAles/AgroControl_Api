# AgroControl API

API para controle completo de insumos agrícolas, criada como projeto de estudo com .NET 10, SQL Server, Entity Framework Core, Redis, RabbitMQ, Docker, testes automatizados e observabilidade.

## Objetivos de aprendizagem

- Consolidar ASP.NET Core e Entity Framework Core.
- Aprender estratégias de cache com Redis.
- Aprender mensageria e processamento assíncrono com RabbitMQ.
- Executar toda a infraestrutura localmente com Docker Compose.
- Aplicar testes unitários, de integração e de arquitetura.
- Implementar logs estruturados e persistência de eventos de observabilidade em SQL Server.

## Status

Projeto em fase inicial de estruturação.
